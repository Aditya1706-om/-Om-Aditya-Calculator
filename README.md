# Modern Neon Glass Calculator

> **SkillCraft Technology Web Development Internship — Task 02**  
> Designed & Developed by **Om Aditya**

A sleek, responsive, and futuristic calculator built with vanilla HTML5, CSS3, and JavaScript featuring modern glassmorphism, dynamic ambient animations, synthesized audio clicks, theme customizer, and interactive history.

---

## ✨ Features

- 🌌 **Animated Ambient Background**: Glowing floating gradient orbs (`floatOrb` animations) with a cyber grid overlay.
- 💎 **Ultra-Modern Glassmorphism**: Frosted glass container with high backdrop blur (`blur(28px)`), luminous borders, and refined typography.
- 🎨 **Multi-Theme Engine**:
  - **Cyber Dark** (Default obsidian space with neon teal/violet)
  - **Neon Violet** (Vibrant electric pink and magenta glow)
  - **Arctic Frost** (Ice-cold cyan and azure aura)
- 🌊 **Micro-Animations & Ripple Waves**: Dynamic material-style radial ripples expanding from the exact click coordinates.
- ⌨️ **Synchronized Keyboard Support**: Pressing physical keys on your keyboard visually animates and presses the matching on-screen buttons.
- 🔊 **Web Audio API Synthesized Sounds**: Tactile audio click feedback synthesized directly in the browser (zero external MP3 files required) with an instant mute toggle.
- 🕒 **Calculation History**: Slide-up glass drawer recording past operations with one-click re-load and history clear options.
- 📋 **Copy to Clipboard**: Quick copy button inside the display with floating toast confirmation.
- 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile screens.

---

## ⌨️ Keyboard Shortcuts

| Key | Action |
| --- | --- |
| `0` – `9` | Input Number |
| `.` | Decimal Point |
| `+`, `-`, `*`, `/`, `%` | Operators (`+`, `−`, `×`, `÷`, `%`) |
| `Enter` or `=` | Calculate Result |
| `Backspace` | Delete Last Character (DEL) |
| `Escape` | All Clear (AC) / Close History |

## 🛠️ Built With

- **HTML5**: Semantic and accessible markup.
- **CSS3**: Custom properties, Glassmorphism (`backdrop-filter`), CSS Grid & Flexbox, Keyframe Animations.
- **JavaScript (ES6+)**: Calculation engine, Web Audio API synthesizer, LocalStorage persistence, DOM event synchronization.
- **Google Fonts**: [Outfit](https://fonts.google.com/specimen/Outfit) & [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono).
